The rules every asset agent must follow

Non-negotiable — these are paid-for lessons
  1. build.py is the source of truth, not the .blend. Anything done by hand in the GUI is destroyed on the next build.
  2. Procedural only. Primitives, modifiers, shader nodes. No downloaded models, no image textures.
  3. Shared code lives in lib/. If two scenes would need it, it belongs in the library — never duplicated into a scene script.
  4. Fixed random.seed() at the top of every build script. Builds must be reproducible.
  5. Preview render before the final, and look at the image. Previews are prefixed preview_ — a preview once overwrote a finished final render.
  6. Run scripts/set_viewport_colors.py after building or the scene is grey in the GUI.
  7. Read matrix_basis, not matrix_world, on appended objects — the depsgraph never evaluates a hidden collection, and everything collapses to one point.
  8. Append once, instance with obj.copy(). Three appends make six duplicate materials.
  9. Never hash two Cycles renders to test for a regression. GPU denoising is not bit-reproducible. Compare object counts and geometry.
  10. Colour crossing to Unity is raised by pow(v, 0.62) — these palettes are authored for Cycles with AgX. Apply it to every surface or none.

Naming and layout, exactly

blender/base/<family>/
├── build.py                    the source of truth
├── <family>.blend              build artifact, overwritten
├── models/<asset>.blend        one file per asset — objects + materials, no camera
└── renders/
    ├── <family>_0001.png       final
    ├── preview_<family>_0001.png
    └── review/                 plan + angles + close-ups
  • Family folder is lowercase, singular or a family plural: hall, huts, map_village.
  • Always build.py — never main.py or <family>_build.py.
  • Build artifact is named after its folder.
  • Asset files are named after the asset: hut_a.blend.

Definition of done, per asset

An agent may not mark an asset complete until all six are true:

  1. models/<asset>.blend exists and opens clean from --factory-startup
  2. A final render exists in renders/ and has been looked at
  3. Triangle count is recorded and is within the budget in 10 · Tech
  4. The asset is recentred on its ground-contact point, not its authoring offset
  5. Materials use the shared palette from lib/materials.py — no ad-hoc colours
  6. The row in PROGRESS.md is moved to Done with the triangle count
